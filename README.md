# Kavya S — Full Stack Portfolio

A personal portfolio website built to showcase my projects, experience, skills, achievements, and certifications.

## Tech Stack

- **Frontend:** React, JavaScript, CSS, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Tools:** Git, GitHub, VS Code

## Features

- Responsive portfolio interface
- About, Skills, Projects, Experience, and Achievements sections
- Project data integrated with a backend API
- MongoDB database integration
- Contact links for Email, Phone, GitHub, and LinkedIn
- Scroll-based reveal effects
